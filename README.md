# مهارت تحلیل نمودار و سناریوی معاملاتی

نسخهٔ ۰٫۱۷٫۰، مرجع پیوت، موج ورودی، حمایت و مقاومت، هدف و ساختار چندبازه‌ای را با قواعد صریح بررسی می‌کند. دو اصلاح این نسخه، پذیرش فهرست کاملِ سطح تا دو هزار مورد و بازگشایی پایدارِ تصمیم ذخیره‌شده در اجراهای جداست. برنامه سفارش ایجاد نمی‌کند.

[دستورهای اصلی مهارت](skills/trade-chart-scenarios/SKILL.md)

[گزارش آزمون و محدودیت‌ها](VALIDATION.fa.md)

[دامنهٔ نسخهٔ عمومی](skills/trade-chart-scenarios/references/public-distribution.fa.md)

برای استفاده، پوشهٔ مهارت را به ابزار پشتیبان مهارت معرفی کنید. اجرای محاسبه‌گرها به پایتون و کتابخانهٔ استاندارد آن نیاز دارد. آزمون‌های عمومی از ریشهٔ مخزن اجرا می‌شوند:

```text
python -X utf8 -B tools/verify_public.py
python -X utf8 -B tools/run_tests.py
```

این بسته ۳۲۰ آزمون عمومی، نمونه‌های مصنوعی و داده‌های تاریخیِ بایننس با مجوز مشخص دارد. مطالعهٔ کامل محلی ۶۰ پروندهٔ واقعی را بررسی کرده است؛ پنج تأیید هندسی، شاهد آمادگی کاملِ معامله نیستند. چهار ابهام آموزشی هنوز بازند. نمونهٔ مثبتِ کامل، سودآوری و اجرای واقعی متاتریدر در این انتشار تأیید نشده‌اند.

اکسل شخصی، متن خصوصی منابع و آرشیوهای قیمت با مجوز بازنشر بررسی‌نشده در مخزن عمومی قرار ندارند. تاریخچهٔ محلی و بستهٔ عمومی اثرانگشت متفاوت دارند؛ مجوز داده را با مجوز کد یکی نگیرید.
